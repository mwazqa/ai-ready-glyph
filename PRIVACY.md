# Privacy

AI Ready Glyph has no INTERNET permission, backend, analytics, advertisements or crash-reporting service.

Android grants broad notification-listener access. The listener rejects unselected source packages before extracting text. Selected notification text is matched in memory and is not written to storage or transmitted.

SharedPreferences store selected packages, user-entered custom phrases, animation assignments and settings. App backup is disabled. In-memory diagnostics contain time, an app label and a result, without notification titles, message bodies or conversation history.

Phone recognition reads public manufacturer, brand and model fields. It does not read an IMEI, serial number or Android ID.

Revoke notification access or clear app data in Android Settings. Uninstalling removes app data. These statements describe AI Ready Glyph, not the AI apps whose notifications it reads.
