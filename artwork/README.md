# Artwork provenance

Notify Glyph uses an original white dot-matrix N monogram and red notification dot on a black background. Android adaptive colour and monochrome variants are included. BuildAppIcon.java regenerates these assets, the SVG and an ignored dist/Notify-Glyph-icon.png preview. The small dot alphabet and generic AI lettering are original project work, covered by MIT. No proprietary Nothing font is bundled.

The separate Glyph Toys preview uses the same N monogram on a circular black background, a 25 x 25 grid of square pixels and a red notification dot in the upper right. Pixels outside the circle are transparent. It is original project artwork covered by MIT and does not include Nothing's Toy badge, which the system adds. Run `java scripts/BuildToyPreview.java` with JDK 17 or 21 from the project root to regenerate artwork/glyph-toy-preview.svg, app/src/main/res/drawable/ic_glyph_toy_preview.xml and an ignored dist/Notify-Glyph-toy-preview.png. The launcher icon is generated separately.

The ChatGPT pixel symbol derives from the official Blossom SVG in [OpenAI's 2025 logo pack](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip). ChatGptSymbol.java stores 25 x 25 coverage; ChatGptTrace.java orders drawing from the inner junctions. The raw SVG is excluded from Git. [OpenAI guidelines](https://openai.com/brand/) apply; separate approval for this adaptation is not claimed.

ClaudeFrames.java contains 12 monochrome frames from a GIF supplied during personal development, preserving its one-second cycle. The raw GIF is excluded because its upstream author and redistribution licence were not established. BuildClaudeFrames.java can convert a locally supplied input; it grants no rights to that input.

The Gemini star is procedural and identifies the Gemini source.

MessagingSymbols.java contains four 25 x 25 pixel symbols generated by `java scripts/BuildMessagingSymbols.java`. The generator draws stylized Discord, Messenger and WhatsApp identifiers and an original generic SMS bubble. These are project-drawn adaptations, not an assertion that the low-resolution shapes are official artwork. The SVG atlas is committed; the PNG reconstruction is generated in dist/. The three brand-identifying symbols are excluded from MIT to the extent third-party rights apply. The generic SMS bubble and generator control code are original MIT project work.

Provider marks and reference-derived data are excluded from MIT. Attribution or conversion to pixels does not clear their rights. [Third-party notices](../THIRD_PARTY_NOTICES.md) describe the limitations.

SocialSymbols.java contains four 25 x 25 symbols generated by `java scripts/BuildSocialSymbols.java`: a stylized Instagram camera, TikTok musical note, X and Facebook f. SocialAnimation.java supplies progressive drawing, a growing lens, echoes and soft pulses. The generator writes artwork/social-symbols.svg and an ignored PNG atlas in dist/. These project-drawn brand adaptations are excluded from MIT to the extent third-party visual rights apply; original generator and animation control code remain MIT. They are not claimed as official or brand-approved artwork.

Local reference files artwork/claude-reference.gif and artwork/openai-blossom.svg are ignored and not needed to compile the committed source.
