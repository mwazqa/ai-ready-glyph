# Naming check for 0.7.0

Ready Glyph is the working name for the expansion beyond AI sources. This review checked publicly returned search results, not reservations or exclusive rights.

| Candidate | GitHub repository-name search | Google Play search |
| --- | --- | --- |
| Ready Glyph | No exact separate ready-glyph / readyglyph project observed; this project's ai-ready-glyph appeared | No exact app title among returned results |
| Glyph Notify | No exact glyph-notify / glyphnotify project observed; glyph-fr/notify is a differently named Rails project | No exact app title among returned results |
| Glyph Signal | Similar names included itsgoksz/glyph-signals and inkclear-ih/glyph-signal-lab | No exact app title among returned results |

GitHub searches used the terms ready glyph, glyph notify and glyph signal with the in:name qualifier. The similar [glyph-signals repository](https://github.com/itsgoksz/glyph-signals) was confirmed through repository metadata; its README was not retrieved. The proposed mwazqa/ready-glyph repository URL returned 404 during the check. The existing repository is retained rather than renamed.

Google Play was checked directly with each candidate in its search interface, using the Polish catalog and English UI. Results are ranked and regional; an unreturned, unpublished, private or newly indexed project may not appear. Absence in these results is not a guarantee that a name is universally unused.
