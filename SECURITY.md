# Security

Only the current development version is maintained. There is no guaranteed response time or security certification.

Report sensitive vulnerabilities through [GitHub private vulnerability reporting](https://github.com/mwazqa/ai-ready-glyph/security/advisories/new). Include version, steps, impact and a minimal redacted example.

Do not post credentials, private notifications, conversation content or identifying device data in public issues. Ordinary build or compatibility bugs belong in the issue template.
